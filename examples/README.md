# Exemplos de contratos — apenas ilustrações

Nenhum JSON desta pasta contém credenciais ou payload real de biometria. Não interpretar os exemplos como contrato nativo oficial Control iD nem como formato criptográfico interoperável validado. Conferir o endpoint e firmware específicos antes de implementar. `encrypted_package_manifest.example.json` é um esboço de metadados: o formato real precisa de uma especificação versionada com serialização, AAD, KDF, assinatura/autenticidade, wrapping, streaming e vetores de teste.
